# Task 3: Linear Regression

## Objective
To implement and understand Simple and Multiple Linear Regression using Python and Scikit-learn.

## Dataset
Housing.csv

The dataset contains house features such as area, bedrooms, bathrooms, stories, parking and furnishing status.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Steps Performed
1. Imported required libraries.
2. Loaded and explored the housing dataset.
3. Checked and handled categorical data using encoding.
4. Split the dataset into training and testing sets.
5. Implemented Simple Linear Regression using area.
6. Implemented Multiple Linear Regression using multiple features.
7. Predicted house prices.
8. Evaluated models using MAE, MSE and R².
9. Visualized actual and predicted house prices.

## Model Results

### Simple Linear Regression
- MAE: 1474748.13
- MSE: 3675286604768.19
- R² Score: 0.2729

### Multiple Linear Regression
- MAE: 970043.40
- MSE: 1754318687330.66
- R² Score: 0.6529

## Conclusion
Multiple Linear Regression performed better than Simple Linear Regression because it uses multiple house features to predict prices instead of relying only on area.
